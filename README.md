# Spider Thief: Night Shift

Browser 3D stealth game.

Play: https://qabia2288.github.io/spider-thief-night-shift/

Controls: WASD, mouse, E to pick up, G to drop, Space to jump after upgrade, Shift to sprint after upgrade, B workshop in the nest, Esc pause.

Five nights, five rooms, loot delivery and persistent upgrades. Desktop browser with WebGL required.

Third-party asset licenses are included alongside the assets.
