- `spider-shell.glb`: original Sharrowkin project geometry created in Blender 5.2.3 through Blender MCP for this task. Body shell only; eight articulated legs are provided by `spider.ts`. Runtime scale 0.3, matching the existing small spider. No external model used.
- `wood_floor.jpg`, `painted_plaster_wall.jpg`: 1024 px derivatives of the corresponding diffuse JPEGs supplied by the user in `tools/JamAssets/NewInterior/Materials`. No license file was present alongside those materials; publication clearance is NOT VERIFIED. Local use requested by the user; no publication performed.
- `human.glb`: Kenney Animated Characters Survivors 1.1, CC0; local `characterMedium.fbx`, `idle.fbx`, `run.fbx`, `survivorMaleB.png`, converted through Blender MCP. License: `Human-Kenney-License.txt`. Runtime follows the existing AI-driven pose via the imported bones.
- `limestone.svg`: original project tile texture; no third-party image.
- Room models retain the licenses in `redesign-rooms`. Architecture retains Kenney CC0 license in `redesign-architecture`.
