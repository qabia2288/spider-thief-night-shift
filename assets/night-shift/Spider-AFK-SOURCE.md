# Animated spider

Downloaded 2026-11-01 from https://afk.ai/auto-rig-models/spider.glb
Source and license declaration: https://afk.ai/auto-rig/spider

The publisher explicitly releases the downloadable sample model, skeleton and
animations as CC0. The original GLB is retained unmodified as spider-afk.glb.
Contains 17 action clips plus Rest Pose. Gameplay uses Idle, Walk, Run, Sneak and
Jump via Three.js AnimationMixer with crossfades. Runtime scales the complete
animal to 18 cm wide; gameplay collision and cargo world scale are unchanged.
