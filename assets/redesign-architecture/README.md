# Архитектурные модели — черновик для интеграции

Готовые оригинальные GLB без изменения геометрии: Kenney Building Kit 1.0, CC0. Источник каждого файла: `tools/JamAssets/NewInterior/Architecture/kenney_building-kit/Models/GLB format/<имя>.glb`; оригинальная лицензия — `Kenney-Building-Kit-License.txt`. Все модели ссылаются на поставляемый `Textures/colormap.png` из исходного комплекта. Пути относительно GLB должны оставаться неизменными.

Размеры — габариты сцены в исходных единицах glTF, XYZ, без пересчёта; ось Y направлена вверх. Размер по X — толщина стен и двери, Z — их протяжённость. Bounds вычислены по accessor min/max и матрицам узлов; возможна избыточная оценка при повороте локальных AABB. Облик и лицевую сторону нужно проверить в игре.

| Файл | Размер XYZ | Минимум XYZ | Максимум XYZ | Назначение |
|---|---|---|---|---|
| `door-rotate-square-a.glb` | 0.25 × 2.10 × 0.925 | -0.125, 0, -0.025 | 0.125, 2.10, 0.90 | Дверное полотно; начало координат около края, а не нижнего центра. |
| `wall-doorway-square.glb` | 0.20 × 2.40 × 2.00 | -0.10, 0, -1 | 0.10, 2.40, 1 | Сегмент стены с дверным проходом, не отдельная рамка. |
| `wall-window-square-detailed.glb` | 0.20 × 2.40 × 2.00 | -0.10, 0, -1 | 0.10, 2.40, 1 | Сегмент стены с окном, не отдельная оконная рама. |
| `border.glb` | 0.20 × 0.30 × 2.00 | 0.05, 0, -1 | 0.25, 0.30, 1 | Архитектурная кромка; origin смещён по X. |
| `floor.glb` | 2.00 × 0.10 × 2.00 | -1, 0, -1 | 1, 0.10, 1 | Плитка пола; верх на Y=0.10. |

Не помещать цельный сегмент стены поверх существующей стены/окна: геометрию и вырезы необходимо согласовать с `WORLD_LAYOUT`, состоянием открывания дверей и видом камеры. Существующий загрузчик нормализует габариты; перед подключением проверить его нормализацию и pivot. Материалам пола/стен из NewInterior не найдено сопроводительных лицензий — в этот пакет они не включены.

Прямой Blender MCP в данной сессии не предоставлен; Blender не использовался, новый `.blend` не создавался. `prepare.py` копирует оригиналы и проверяет GLB-заголовки, локальные ресурсы и bounds; это не проверка рендеринга или полная валидация glTF. Игровой код и manifest не менялись.
